# Brittany Taylor Square Gallery Portfolio

This is a GitHub Pages-ready portfolio site with a minimal black-text design, equal square project tiles, and hover-only project titles on desktop.

## Files
- `index.html` - two-column square gallery homepage
- `about.html` - editorial About page
- `project.html` - reusable project page
- `styles.css` - styles and mobile layout
- `script.js` - project page content map
- `images/` - square placeholder images

## Replace images
Use square campaign images for the closest visual result. Replace files inside `images/` and keep the same filenames, or update image paths in `index.html` and `script.js`.

## GitHub Pages
Upload all files and the `images` folder to the root of your GitHub repository. `index.html` must be at the top level.

## Mobile behavior
On screens smaller than 760px, the gallery becomes one column and project titles are visible automatically because mobile devices do not support hover in the same way desktops do.
