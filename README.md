# Brittany Taylor Final Portfolio Site

This version includes:

- Smaller centered two-column square gallery
- True square project tiles
- Hover titles on desktop
- One-column mobile layout with titles visible
- Balanced About page typography
- Smaller, balanced project page image and body text
- Removed Role and Note sections from project pages
- Previous Project and Next Project navigation on each project page
- Return to Top link on the homepage

## Upload to GitHub Pages

Upload all files and the `images` folder to the root of your GitHub repository. `index.html` must remain at the top level.

## Replace images

Use square images for the cleanest homepage result. Replace the files in `images/` and keep the same filenames, or update paths in `index.html` and `script.js`.

## Edit project order

To change the back and forth order, edit the `projectOrder` array in `script.js`.

## Project navigation

Project pages use generic Previous Project / Back to Work / Next Project labels while still linking to the correct previous and next projects in the sequence.
