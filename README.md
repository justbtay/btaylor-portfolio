# Brittany Taylor Portfolio Site

This is a GitHub Pages-ready portfolio site built around a two-column image gallery with hover-only project titles.

## Files

- `index.html` - two-column hover gallery homepage
- `about.html` - editorial-style About page
- `project.html` - reusable project detail page
- `styles.css` - site styling
- `script.js` - project page content mapping
- `images/` - placeholder SVG images to replace with final campaign imagery

## How to use on GitHub Pages

Upload all files and the `images` folder to the root of your GitHub repository. `index.html` must be at the top level of the repo.

## How to replace imagery

Replace the SVG files in the `images` folder with your final campaign images. Keep the filenames the same, for example:

- `images/hacks.svg` can become `images/hacks.jpg`
- If you change the extension, update the matching image path in `index.html` and `script.js`

Recommended image crop: vertical 4:5 for homepage tiles. Use high-quality JPG or PNG files.

## Before publishing

Replace placeholder text, update the contact email, add your real LinkedIn URL, and use only approved public campaign imagery and copy.
