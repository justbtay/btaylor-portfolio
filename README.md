# Brittany Taylor Portfolio

GitHub Pages-ready static portfolio.

## Publish
Upload every file and the entire `images` folder to the root of the GitHub repository. In GitHub Pages, deploy from the `main` branch and `/ (root)` folder.

## Edit content
All project names, copy, awards, videos, and gallery image paths are in `projects.js`.

## Replace an image
Replace the matching file in `images/` while keeping the filename unchanged. If the filename changes, update the path in `projects.js`.

## Before publishing
Update the placeholder Contact email and LinkedIn URL in `about.html`. Confirm all campaign assets, claims, links, and awards are approved for public use.
