# Brittany Taylor Portfolio Website V2

This version is designed to feel much closer to the reference portfolio: minimal header, white background, image-first work archive, understated project titles, and simple case study pages.

## Files to upload to GitHub

- `index.html` - Work archive homepage
- `about.html` - About page
- `project.html` - Reusable project case study page
- `styles.css` - Minimal portfolio styling
- `script.js` - Project content used by the campaign pages

## Important publishing note

The site includes draft portfolio language based on your work context. Before publishing publicly, replace all placeholder visuals and remove any confidential, unapproved, unreleased, or proprietary details. Use only approved campaign images, public press links, and cleared copy.

## GitHub Pages setup

Upload these files at the top level of your repository. GitHub Pages will look for `index.html` in the root.

## How to customize

1. Replace the placeholder thumbnails with approved campaign images.
2. Edit project copy in `script.js`.
3. Replace the About page with your approved public bio.
4. Commit changes and GitHub Pages will update the site.
