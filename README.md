# Brittany Taylor Portfolio Website

This is a static portfolio site inspired by the structure of Dana Flax's public portfolio: minimal navigation, large editorial typography, a visual work grid, an about section, and individual case study templates.

## Files

- `index.html` Homepage with Work and About sections
- `project.html` Reusable case study template
- `styles.css` Full responsive styling
- `script.js` Filter buttons, year update, and case study title loading

## How to customize

1. Replace the name, email, and bio copy in `index.html`.
2. Swap the placeholder project cards for real campaign titles.
3. Add approved project images by replacing each `.project-art` block with an `<img>` if desired.
4. Update `project.html` with approved campaign details, your role, challenge, approach, and outcomes.
5. Publish on Webflow, Squarespace, GitHub Pages, Netlify, or Vercel.

## Notes

The package intentionally does not copy Dana Flax's images or exact copy. It uses a similar editorial portfolio pattern with original placeholder content and styling.
